# 📋 VK Reposter Pro

Расширение для Chrome/Edge для массового кросспостинга записей ВКонтакте в несколько групп одновременно.

## ✨ Возможности

- 🔘 **Кнопки на постах** - нажмите "📋 Репостер" прямо на посте
- 📋 **Копия от имени группы** - пост публикуется как новый (без указания источника)
- 🔄 **Репост** - классический репост с указанием источника
- 🖼 **Правильное копирование фото** - фото загружаются на сервер группы (источник не виден!)
- ⏰ **Отложенный постинг** - выберите дату и время публикации
- ✏️ **Редактирование текста** - измените текст перед публикацией
- 💾 **Запоминание групп** - сохраняет выбранные группы
- 🔍 **Поиск по группам** - быстрый поиск нужной группы
- 📊 **Прогресс-бар** - отслеживание процесса отправки
- 🎨 **Современный дизайн** - тёмная тема

## 🚀 Установка

1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку с расширением
5. Готово!

## 🔑 Авторизация

1. Нажмите на иконку расширения
2. Нажмите "Авторизоваться ВК"
3. Разрешите доступ
4. Готово!

Или вставьте токен вручную.

## 📖 Использование

### Способ 1: Кнопка на посте (рекомендуется)
1. Откройте ВКонтакте
2. Найдите пост который хотите репостнуть
3. Нажмите кнопку **"📋 Репостер"** под постом
4. Откроется popup с уже загруженным постом
5. Выберите группы и настройки
6. Нажмите "🚀 Отправить в группы"

### Способ 2: Через popup
1. Скопируйте ссылку на пост
2. Нажмите на иконку расширения
3. Вставьте ссылку
4. Нажмите "📌 Загрузить пост"
5. Выберите группы и настройки
6. Нажмите "🚀 Отправить в группы"

## ⚙️ Настройки

### Режимы публикации

**📋 Копия (от имени группы)** - рекомендуется
- Пост публикуется как новый
- Фото загружаются на сервер группы
- Источник НЕ виден (даже при клике на фото)
- Можно редактировать текст

**🔄 Репост**
- Классический репост
- Указывается источник
- Нельзя редактировать текст

### ⏰ Отложенный постинг

1. Поставьте галочку "Отложить публикацию"
2. Выберите дату и время
3. Пост опубликуется автоматически в указанное время

## 🛡️ Безопасность

- Токен хранится локально в Chrome Storage
- Все запросы идут напрямую к VK API
- Задержка 2.5 секунды между постами (защита от бана)
- Никакие данные не отправляются на сторонние серверы

## ⚠️ Важно

- Используйте задержку минимум 2-3 секунды между постами
- Не злоупотребляйте массовыми рассылками
- Соблюдайте правила ВКонтакте
- У вас должны быть права админа/редактора в группах

### Как работает копирование фото

При выборе режима "Копия (от имени группы)":
1. Расширение скачивает оригинальное фото
2. Загружает его на сервер каждой группы через `photos.getWallUploadServer`
3. Сохраняет через `photos.saveWallPhoto`
4. Публикует пост с новым ID фото

Результат: фото принадлежит группе, источник не виден!
